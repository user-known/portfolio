# Portfolio

Personal portfolio for Vignesh Balakumar. Plain HTML, CSS and JS. No build step.

## Pages
- `index.html` home
- `about.html` about
- `projects.html` all projects (filterable list)
- `case-study.html` case study template (Acme Interiors)
- `projects.html` all projects, with filters

## Before publishing
- Replace `hello@yourdomain.com` (the `EMAIL` line in each file's script, plus the visible text and `mailto:` links).
- Replace the `#` links for LinkedIn, Behance and the other case studies.
- Replace the gray "Add image" blocks and the "Add..." placeholder text.
- General Sans is loaded from Fontshare. Check its license for your use.

## Hosting on GitHub Pages
Settings > Pages > Deploy from a branch > `main` / root. The site appears at
`https://<username>.github.io/<repo>/`.
